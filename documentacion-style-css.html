Documentacion de css/style.css

Esta pagina explica solamente los selectores y propiedades que existen actualmente en css/style.css. El CSS principal organiza una pagina construida con tablas, celdas, contenido principal, anuncios y un pie de pagina.

1. Como leer CSS

Una regla CSS tiene esta estructura:

selector {
    propiedad: valor;
}
TerminoSignificadoEjemplo actual
SelectorIndica que elementos HTML recibiran el estilo.body, .pagina, nav a
PropiedadAspecto que se quiere modificar.color, padding, width
ValorConfiguracion de la propiedad.white, 15px, 100%
ClaseNombre reutilizable escrito con un punto en CSS y con class en HTML..tabla-casos
Selector agrupadoVarios selectores separados por comas que comparten reglas..columna-contenido, .columna-lateral
Selector descendienteUn espacio indica que el segundo elemento esta dentro del primero.nav a
Hijo directoEl simbolo > exige que el elemento este inmediatamente dentro del anterior..pagina > tbody > tr > td

2. Reglas globales

body

body contiene todo lo visible. Algunas propiedades de texto pueden heredarse por los elementos internos.

ReglaFuncion
background-color: transparentDeja transparente el fondo general.
font-family: 'Times new roman', Tahoma, Geneva, Verdana, sans-serifDefine una lista de fuentes de respaldo. El navegador prueba la primera disponible y termina usando una familia generica sin serifas.
color: #333333Establece el color de texto base. Es un gris oscuro hexadecimal.
line-height: 1.6Hace que la altura de cada linea sea 1.6 veces el tamaño de la fuente.
margin: 0Elimina el margen exterior predeterminado del navegador.

table

table selecciona todas las tablas, incluso las anidadas.

ReglaFuncion
border-collapse: collapseUne los bordes vecinos de las celdas. En el CSS actual no se usa border-spacing.

3. Tabla principal y columnas

.pagina

ReglaFuncion
width: 100%Hace que la tabla ocupe todo el ancho disponible.
.pagina > tbody > tr > td { padding: 0; }Quita el espacio interno de las celdas principales. El navegador suele insertar tbody aunque no se escriba.

.tabla-completa, .tabla-navegacion y .tabla-anuncios comparten width: 100% porque las tres deben ocupar el ancho disponible.

.tabla-navegacion

.tabla-navegacion td {
    padding: 0 15px;
}

Las celdas del menu reciben 0 píxeles arriba y abajo, y 15 píxeles a izquierda y derecha. Con dos valores, padding se interpreta como vertical horizontal.

.columna-contenido y .columna-lateral

ClaseUsoReglas
.columna-contenidoCelda que contiene main.vertical-align: top; width: 75%
.columna-lateralCelda que contiene aside y anuncios.vertical-align: top; width: 15%

vertical-align: top alinea el contenido al comienzo vertical de la celda. El porcentaje es relativo al ancho de la tabla padre.

Fondo de .columna-lateral

ReglaFuncion
background-image: url('../imagenes/colombia-flag.gif')Carga el GIF indicado por url().
background-size: coverEscala la imagen para cubrir toda la celda; puede recortar parte.
background-position: centerCentra la imagen de fondo.
background-repeat: no-repeatEvita que el fondo se repita como mosaico.
color: whiteDefine el color heredable del texto lateral.
border-radius: 8pxRedondea las esquinas.

7. Texto, herencia y cascada

SelectorReglaFuncion
pcolor: blackDefine en negro todos los parrafos.
.pagina td ppadding: 25pxAñade espacio interior a los parrafos dentro de celdas de .pagina.
footer pmargin: 0; font-size: 0.95rem; color: inheritQuita margen, reduce tamaño y hereda el color del footer.
footer .tabla-footer ppadding: 0Evita que los parrafos del footer reciban los 25 píxeles generales.
h2color: black; text-align: center; font-weight: bold; font-size: 1.9remConfigura los titulos de segundo nivel.
licolor: blackConfigura el texto de los elementos de listas.
Herencia: color, font-family y line-height pueden pasar del padre a sus hijos. inherit lo solicita explicitamente. El padding, el margin, el ancho y el alto no se heredan normalmente.

Cascada: si varias reglas afectan al mismo elemento, el navegador compara especificidad, orden y prioridad. footer .tabla-footer p es mas especifico que .pagina td p, por eso puede cambiar su padding a cero.
